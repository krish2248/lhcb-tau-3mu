# LHCb τ → μμμ decay classifier

**Status: in progress.** The code has not been published here yet.

An XGBoost classifier with SHAP explanations on LHCb data from Kaggle's
["Flavours of Physics"](https://www.kaggle.com/c/flavours-of-physics) challenge,
designed to pass the challenge's real-vs-simulated agreement test and
mass-correlation test.

Stack: Python, XGBoost, SHAP
